Transkript

Das Transkript erscheint hier, sobald gesprochen wird.
Alles läuft lokal im Browser – es werden keine Audiodaten an einen Server dieses Tools gesendet. (Die Web-Speech-Transkription nutzt je nach Browser einen Cloud-Dienst des Browserherstellers.) Die Sprecherzuordnung ist heuristisch (Tonhöhe & spektraler Schwerpunkt) und funktioniert am besten bei deutlich unterschiedlichen Stimmen.

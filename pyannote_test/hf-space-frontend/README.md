# Sprecher-Analyse (App)

Eigenständige PWA-Oberfläche der Sprecher-Analyse. Spricht das
zugangsgeschützte API-Backend (Space `Monstermango/diarization`) an:
Aufnahme/Upload → Diarization + Transkription auf ZeroGPU → Ergebnisansicht,
Verlauf und Markdown-Ablage im privaten Dataset.
